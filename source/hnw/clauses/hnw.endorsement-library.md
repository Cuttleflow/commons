An endorsement applies only if its code is shown in the schedule. Each endorsement changes this policy only as it states, and is read together with the variables shown for it in the schedule. Where an endorsement and the rest of this policy conflict, the endorsement applies to the extent of the conflict. If a variable an endorsement needs is not shown in the schedule, the default stated in the endorsement applies; if it has no default, the endorsement does not apply until we show the variable in the schedule.

| Code | Endorsement | Effect |
|---|---|---|
| E01 | Extended Replacement 50% | Raises extended replacement to 50% of the building sum insured |
| E02 | High Hazard Zone | Sets a special excess for flood and storm |
| E03 | Bushfire-Prone Home | Sets a special excess for bushfire and the care of the land around the home |
| E04 | Northern Australia | Sets a special excess for cyclone |
| E05 | Heritage-Listed Home | Sets the basis for repairing heritage features |
| E06 | Building Works | Continues cover during building works |
| E07 | Unoccupied Home | Continues cover while the home is unoccupied |
| E08 | Short-Stay Letting | Covers the home while it is let for short stays |
| E09 | Building Valuation to Follow | Limits extended replacement until a valuation is given to us |
| E10 | Vault Storage | Sets the cover for jewellery and watches kept in a vault |
| E11 | Jewellery Kept in a Safe | Asks for valuable jewellery to be kept in a safe when not worn |
| E12 | Item Valuations to Follow | Limits cover for specified items whose valuations are still to be given to us |
| E13 | Company or Trust as Insured | Names the people who live in a home owned by a company or trust |
| E14 | Interested Party | Notes a financier or other party's interest |
| E15 | Lloyd's Underwriters | Adds Lloyd's several liability, service of suit and complaints terms |
