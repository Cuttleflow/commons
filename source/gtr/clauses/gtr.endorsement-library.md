An endorsement applies only if its code is shown in the schedule. Each endorsement changes this policy only as it states, and is read together with the variables shown for it in the schedule. Where an endorsement and the rest of this policy conflict, the endorsement applies to the extent of the conflict. If a variable an endorsement needs is not shown in the schedule, the default stated in the endorsement applies; if it has no default, the endorsement does not apply until we show the variable in the schedule.

| Code | Endorsement | Effect |
|---|---|---|
| E01 | Pre-existing Medical Conditions | Accepts named pre-existing conditions |
| E02 | Leisure Extension | Extends leisure travel and adds leisure-only trips for named directors |
| E03 | Hazardous Activities | Writes back named hazardous activities |
| E04 | Epidemic and Pandemic Disruption | Covers disruption from a traveller's own diagnosis or quarantine |
| E05 | Manual Work Overseas | Writes back named manual work |
| E06 | Long-Term Assignment | Extends the maximum trip duration for named assignments |
| E07 | Increased Personal Accident Benefits | Increases the personal accident capital sum |
| E08 | Non-Employee Travellers | Adds consultants, advisers and guests as insured persons |
| E09 | Domestic Travel Only | Limits cover to trips within Australia |
| E10 | Employees Based Outside Australia | Adds employees based outside Australia |
