An endorsement applies only if its code is shown in the schedule. Each endorsement changes this policy only as it states, and is read together with the variables shown for it in the schedule. Where an endorsement and the rest of this policy conflict, the endorsement applies to the extent of the conflict. If a variable an endorsement needs is not shown in the schedule, the endorsement does not apply until we show the variable in the schedule.

| Code | Endorsement | Effect |
|---|---|---|
| E04 | Difference in Conditions | Drop-down cover where the underlying D&O insurance does not pay for a listed reason |

Endorsements E01, E02 and E03 are not yet available in this version. A schedule must not show any of them.
