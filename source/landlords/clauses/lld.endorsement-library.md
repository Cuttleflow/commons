An endorsement applies only if its code is shown in the schedule. Each endorsement changes this policy only as it states, and is read together with the variables shown for it in the schedule. Where an endorsement and the rest of this policy conflict, the endorsement applies to the extent of the conflict. If a variable an endorsement needs is not shown in the schedule, the default stated in the endorsement applies; if it has no default, the endorsement does not apply until we show the variable in the schedule.

| Code | Endorsement | Effect |
|---|---|---|
| E01 | Accidental Damage | Adds cover for accidental damage by anyone other than a tenant |
| E02 | Higher Weekly Rent | Raises the weekly rent limit |
| E03 | Pet Damage | Covers damage by a tenant's pet that the agreement allows |
| E04 | Short-Stay Letting | Covers the property while it is let for short stays |
| E05 | Rooming House or Student Accommodation | Sets the terms for a property let by the room |
| E06 | Specialist Disability or Supported Accommodation | Sets the terms for supported accommodation |
| E07 | Agreed Value | Insures the building for an agreed value |
| E08 | Building Works | Continues cover during building works |
| E09 | Unoccupied Property | Continues cover while the property is unoccupied |
| E10 | Heritage-Listed Building | Sets the basis for repairing heritage features |
| E11 | Interested Party | Notes a financier or other party's interest |
| E12 | Lloyd's Underwriters | Adds Lloyd's several liability, service of suit and complaints terms |
| E13 | Self-Managed Property | Sets the terms where you manage the property yourself |
