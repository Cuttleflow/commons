since: 1.0.0

Headings are for convenience only. A reference to legislation includes any legislation that amends or replaces it. A reference to a clause by its heading is a reference to that clause as it appears in this wording. A reference to an endorsement by its code is a reference to that endorsement in the [[ref:trv.endorsement-library|heading]], and it applies only if the schedule shows it.
