An endorsement applies only if its code is shown in the schedule. Each endorsement changes this policy only as it states, and is read together with the variables shown for it in the schedule. Where an endorsement and the rest of this policy conflict, the endorsement applies to the extent of the conflict. If a variable an endorsement needs is not shown in the schedule, the default stated in the endorsement applies; if it has no default, the endorsement does not apply until we show the variable in the schedule.

| Code | Endorsement | Effect |
|---|---|---|
| E01 | Pre-existing Medical Conditions | Accepts named pre-existing conditions |
| E02 | Snow Sports | Covers recreational skiing and snowboarding |
| E03 | Adventure and Extreme Activities | Writes back named extreme activities |
| E04 | Annual Multi-Trip | Covers every trip in a year |
| E05 | Travel Within Australia | Covers trips within Australia |
| E06 | One-Way Trip or Working Holiday | Covers one-way trips and working holidays |
| E07 | Business Meetings and Conferences | Covers light business on a leisure trip |
| E08 | Large Campervans and Motorhomes | Covers large campervans |
| E09 | Pregnancy Extension | Extends pregnancy cover to week 36 |
| E10 | Epidemic and Pandemic Disruption | Covers disruption from your own diagnosis or quarantine |
| E11 | Cancel for Any Reason | Pays 75% of a cancellation for any reason |
| E12 | Portable Electronics | Raises the per-item limit for named electronics |
| E13 | Wedding and Event Cancellation | Covers cancellation of a named wedding or event |
| E14 | Golf | Covers golf equipment and green fees |
| E15 | Senior Traveller | Extends the age limit to 85 |
