An endorsement applies only if its code is shown in the schedule. Each endorsement changes this policy only as it states, and is read together with the variables (sub-limits, excesses, conditions and additional premium) shown for it in the schedule. Except as an endorsement expressly varies them, all terms of this policy continue to apply to cover provided under an endorsement.

| Code | Endorsement | Effect |
|---|---|---|
| E01 | Facility-based Intrapartum Midwifery Care | Varies the Obstetrics exclusion for facility-based intrapartum care by midwives |
| E02 | Clinical Trials and Approved Research | Varies the Clinical Trials exclusion for named, ethics-approved trials |
| E03 | Practice Entity as Named Insured | Adds the practice company, partnership or trust as an insured |
| E04 | Increased Inquiry Costs Sub-limit | Increases the inquiry costs sub-limit |
| E05 | Extended Reporting Period | Records the purchase of the 12-month extended reporting period |
| E06 | Extended Run-off Cover | Extends the 72-month automatic run-off period |
| E07 | Cosmetic and Aesthetic Procedures | Covers the non-surgical cosmetic procedures named |
| E08 | Worldwide Territorial Extension | Covers services provided temporarily outside Australia, except the USA and Canada |
| E09 | Telehealth to Overseas Patients | Covers telehealth from Australia to patients in the countries named |
| E10 | Animal-assisted Therapy Program | Extends Therapy Animals to a structured program |
| E11 | First Aid and Event Medical Services | Covers first aid and event health services at named events |
| E12 | Second Reinstatement of the Limit | Provides a further reinstatement of the Section A limit |
| E13 | Physiotherapy | Profession terms for physiotherapists: covered techniques, conditions and exclusions |
| E14 | Psychology and Counselling | Profession terms for psychologists and counsellors: counsellor eligibility, sub-limits and exclusions |
| E15 | Dental and Oral Health | Profession terms for dental practitioners: covered procedures, sedation, conditions and exclusions |
