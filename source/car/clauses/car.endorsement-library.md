An endorsement applies only if its code is shown in the schedule. Each endorsement changes this policy only as it states, and is read together with the variables shown for it in the schedule. Where an endorsement and the rest of this policy conflict, the endorsement applies to the extent of the conflict. If a variable an endorsement needs is not shown in the schedule, the default stated in the endorsement applies; if it has no default, the endorsement does not apply until we show the variable in the schedule. These endorsements are for use with this wording at version 2.1.x.
