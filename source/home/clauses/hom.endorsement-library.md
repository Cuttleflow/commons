An endorsement applies only if its code is shown in the schedule. Each endorsement changes this policy only as it states, and is read together with the variables shown for it in the schedule. Where an endorsement and the rest of this policy conflict, the endorsement applies to the extent of the conflict. If a variable an endorsement needs is not shown in the schedule, the default stated in the endorsement applies; if it has no default, the endorsement does not apply until we show the variable in the schedule.

| Code | Endorsement | Effect |
|---|---|---|
| E01 | Accidental Damage | Adds cover for accidental damage |
| E02 | Flood Excess | Applies a separate excess for flood |
| E03 | Portable Contents | Covers contents you carry away from the home |
| E04 | Home Business | Covers business equipment and liability for a home business |
| E05 | Short-Stay Letting | Covers the home while it is let for short stays |
| E06 | Specified Valuables | Insures named valuables for their stated value |
| E07 | Strata Lot Owner | Covers your fixtures and the body corporate excess for a strata lot |
| E08 | Agreed Value | Insures the building for an agreed value |
| E09 | Heritage-Listed Home | Sets the basis for repairing heritage features |
| E10 | Building Works | Continues cover during building works |
| E11 | Unoccupied Home | Continues cover while the home is unoccupied |
| E12 | Interested Party | Notes a financier or other party's interest |
| E13 | Lloyd's Underwriters | Adds Lloyd's several liability, service of suit and complaints terms |
