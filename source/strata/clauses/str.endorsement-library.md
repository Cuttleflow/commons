An endorsement applies only if its code is shown in the schedule. Each endorsement changes this policy only as it states, and is read together with the variables shown for it in the schedule. Where an endorsement and the rest of this policy conflict, the endorsement applies to the extent of the conflict. If a variable an endorsement needs is not shown in the schedule, the default stated in the endorsement applies; if it has no default, the endorsement does not apply until we show the variable in the schedule.

| Code | Endorsement | Effect |
|---|---|---|
| E01 | Flood Cover | Adds cover for flood |
| E02 | Known Defect | Records a known defect and how it is covered |
| E03 | Major Works | Covers named major works on agreed terms |
| E04 | Combustible Cladding | Records combustible cladding and the terms that apply |
| E05 | Water Damage Excess | Applies a separate excess for escape of liquid |
| E06 | Short-Term Letting | Confirms cover where lots are let for short stays |
| E07 | Heritage-Listed Building | Sets the basis for repairing heritage features |
| E08 | Interested Party | Notes a financier or other party's interest |
| E09 | Lloyd's Underwriters | Adds Lloyd's several liability, service of suit and complaints terms |
| E10 | Unoccupied Building | Continues cover while the building is unoccupied |
| E11 | Commercial Occupancy | Records a higher-hazard commercial occupancy |
