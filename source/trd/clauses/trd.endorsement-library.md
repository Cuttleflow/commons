An endorsement applies only if its code is shown in the schedule. Each endorsement changes this policy only as it states, and is read together with the variables shown for it in the schedule. Where an endorsement and the rest of this policy conflict, the endorsement applies to the extent of the conflict. If a variable an endorsement needs is not shown in the schedule, the default stated in the endorsement applies; if it has no default, the endorsement does not apply until we show the variable in the schedule.

We attach the endorsements that apply to the trade and the work you tell us about. Each endorsement says what it changes. An endorsement that sets a condition does not let us refuse a claim because the condition was not met, except as [[ref:trd.cond.insurance-contracts-act]] allows.

| Code | Endorsement | Effect |
|---|---|---|
| E01 | Hot Work Conditions | Sets conditions for welding, cutting, grinding and other hot work |
| E02 | Work at Height | Limits liability cover to work up to the height limit |
| E03 | Excavation Depth | Limits liability cover to excavation up to the depth limit |
| E04 | Underground Services Conditions | Sets steps to take before breaking ground near services |
| E05 | Waterproofing | Sets the standard for waterproofing work and a special excess |
| E06 | Roof Work Conditions | Sets conditions for opened roofs and a special excess |
| E07 | Plumbing and Gas Work Conditions | Sets licensing and testing conditions and a special excess |
| E08 | Tree Work Limit | Limits liability cover for felling and lopping trees |
| E09 | Alarm and Monitoring Systems | Excludes the failure of an alarm system to operate |
| E10 | Pest and Weed Control | Excludes the failure of a treatment and sets chemical conditions |
| E11 | Subcontractors | Requires certificates of currency from subcontractors |
| E12 | Named Principals | Names principals and the terms their contracts require |
| E13 | Interested Party | Notes a financier or other party's interest in mobile plant |
| E14 | Lloyd's Underwriters | Adds Lloyd's several liability, service of suit and complaints terms |
| E15 | Residential Building Work | Records that statutory home warranty insurance is separate |
