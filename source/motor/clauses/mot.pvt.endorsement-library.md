An Endorsement applies only where its code is shown in the Schedule. Each modifies only the clauses it names, and is read together with the variables shown for it in the Schedule. Other terms of this Policy continue to apply. If a variable an Endorsement needs is not shown in the Schedule, the default in [[ref:mot.pvt.appendix.default-schedule-values]] applies; if there is none, the Endorsement does not apply until we show the variable in the Schedule.

| Code | Endorsement |
|---|---|
| E05 | Agreed Value |
| E06 | Increased Windscreen Cover |
| E10 | Extended Hire Vehicle |
| E14 | Electric and Hybrid Vehicles |
