This table says which of [[ref:bpk.section.general-exclusions]] apply to which section. An exclusion applies to every section not named in the second column, and applies as modified to the sections named in the third column.

| [[ref:bpk.excl.terrorism|heading]] | None | [[ref:bpk.section.property-damage|heading]]: subject to the Terrorism Insurance Act 2003 (Cth); [[ref:bpk.section.business-interruption|heading]]: subject to the Terrorism Insurance Act 2003 (Cth) |
| [[ref:bpk.excl.nuclear|heading]] | None | None |
| [[ref:bpk.excl.asbestos|heading]] | None | None |
| [[ref:bpk.excl.mould|heading]] | [[ref:bpk.section.tax-audit|heading]]; [[ref:bpk.section.cyber|heading]]; [[ref:bpk.section.management-liability|heading]] | None |
| [[ref:bpk.excl.pollution|heading]] | [[ref:bpk.section.liability|heading]] ([[ref:bpk.liability.excl.pollution]] applies instead); [[ref:bpk.section.tax-audit|heading]]; [[ref:bpk.section.cyber|heading]] | None |
| [[ref:bpk.excl.electronic-data|heading]] | [[ref:bpk.section.cyber|heading]] | [[ref:bpk.section.property-damage|heading]]: except the data benefit the exclusion names; [[ref:bpk.section.business-interruption|heading]]: except the data benefit the exclusion names; [[ref:bpk.section.equipment|heading]]: except the data benefit the exclusion names |
