heading: Unsupported Software
since: 1.4.0
status: draft
---

arising from a cyber event that exploits a known vulnerability in software or an operating system that has reached end-of-life and is no longer supported by the vendor with security patches — unless [[ref:cy.end.e03]] is shown in the schedule, or you can demonstrate that you had implemented reasonable compensating controls (such as network segmentation, application whitelisting, or virtual patching).
