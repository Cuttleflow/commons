An endorsement applies only if its code is shown in the schedule. Each endorsement changes this policy only as it states, and is read together with the variables shown for it in the schedule. Where an endorsement and the rest of this policy conflict, the endorsement applies to the extent of the conflict. If a variable an endorsement needs is not shown in the schedule, the default stated in the endorsement applies; if it has no default, the endorsement does not apply until we show the variable in the schedule.

| Code | Endorsement | Effect |
|---|---|---|
| E01 | Operational Area B | Extends cover to operational area B, on conditions and a special excess |
| E02 | Vessels Over 24 Metres | Sets survey and crewing conditions for a vessel over 24 metres |
| E03 | Passenger Vessels | Sets passenger conditions and the passenger excess for a Class 1 vessel |
| E04 | Swimming and Snorkelling | Covers liability for passengers swimming and snorkelling from the vessel, on conditions |
| E05 | Scuba Diving | Covers liability for scuba diving from the vessel, on conditions |
| E06 | Overnight Passengers | Sets the conditions for carrying passengers overnight |
| E07 | Northern Waters in the Cyclone Season | Requires a cyclone plan and sets a named cyclone excess |
| E08 | Swing Mooring | Sets the conditions for a vessel kept on a swing mooring |
| E09 | Lay-up and Port Risks | Applies the Institute port risks clauses during a declared lay-up, with a return of premium |
| E10 | Loss of Hire | Pays an agreed daily amount while the vessel is out of service after insured damage |
| E11 | Disbursements and Increased Value | Insures an amount above the agreed value for a total loss |
| E12 | Queensland Marine Pollution and Wreck Removal | Sets the minimum pollution and wreck removal cover that Queensland law requires |
| E13 | Towage of Own Barges | Allows the vessel to tow your own barges and workboats |
| E14 | Fishing Vessels | Sets the terms for fishing gear, catch and fishing operations |
| E15 | Hire and Drive Vessels | Sets the conditions for hiring the vessel without crew |
| E16 | Condition Survey | Requires a condition and valuation survey for a timber or older vessel |
| E17 | High-Speed Vessels | Sets the conditions for a vessel capable of more than 35 knots |
