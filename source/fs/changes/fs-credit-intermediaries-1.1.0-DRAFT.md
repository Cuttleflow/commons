Remediation following the Claude pre-review of 2 November 2026. This wording is now built on version 1.1.0 of the Financial Services base wording, so it includes every change listed in the base wording's changes.

- Lender Claims Buy-back: if the schedule shows no sub-limit, the default is $250,000 in the aggregate for the policy period.
- 12-Month Automatic Run-off: now says that ceasing to hold the credit licence or to be a credit representative is ceasing to practise under Run-Off Cover. The 12-month period applies despite the base statement that automatic cover ends at the end of the policy period. If both apply, the longer period applies and the limit is not increased.
- Default set for underwriter confirmation: Lender Claims Buy-back sub-limit of $250,000 in the aggregate where the schedule shows none.
