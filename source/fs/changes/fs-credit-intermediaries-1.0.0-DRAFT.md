First release as an integrated wording, built on the Financial Services PI base 1.0.0-DRAFT. It replaces the endorsement MERIDIAN-PI-MORT-v1.0.0 (June 2026), whose carve-back from the PI base Financial Services exclusion was only in a notes box, and the finance limb of MERIDIAN-PI-MOTR-v1.0.0.

- Deleted: the conflict-of-interest exclusion. Best interests allegations are the main claim, and RG 210 requires cover for them.
- Lender claims are excluded by default, with a buy-back endorsement. Commission clawback is always excluded.
- Optional endorsements: Lender Claims Buy-back (adds cover), Motor Dealer Finance (adds cover), Unregulated Commercial Finance (adds cover) and 12-Month Automatic Run-off (adds cover).
