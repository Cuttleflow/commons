The tables show which exclusions apply to each section. "Applies" means the exclusion applies in full. "Carve-back" means the exclusion applies except to the extent its own text preserves cover. "No" means the exclusion does not apply to that section. The tables are a guide only; the exclusions govern.

**Occurrence sections**

|---|---|---|
| Contractual Liability | Carve-back | Carve-back |
| Excluded Goods | Applies | No |
| Property You Own, Hire or Lease | Carve-back | Carve-back |
| Unexplained Shortages | Carve-back | No |
| Theft From Unattended Vehicles | Carve-back | No |
| Seizure and Confiscation | Carve-back | Carve-back |
| Dishonest and Deliberate Acts | Carve-back | Carve-back |
| Insolvency and Financial Default | Carve-back | Applies |
| Your Fees and Charges | Carve-back | Applies |
| Known Claims and Circumstances | Carve-back | Carve-back |
| Fines, Penalties and Punitive Damages | Carve-back | Carve-back |
| USA and Canada | Applies | Applies |
| Cyber Event | Carve-back | Carve-back |
| Pollution | Carve-back | Carve-back |
| Asbestos | Applies | Applies |
| Employers' Liability | No | Applies |
| Motor Vehicles | No | Carve-back |
| Aircraft and Watercraft | No | Carve-back |
| War and Terrorism | Applies | Carve-back |
| Nuclear | Applies | Applies |
