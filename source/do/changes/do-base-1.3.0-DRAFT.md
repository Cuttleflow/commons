This is the first release of the Meridian Directors and Officers wording built from clause source in the Commons. It replaces version 1.2.0 (July 2026), which was published as a page without clause source. Changes from version 1.2.0:

- Clause numbers are removed. Each clause is identified by its heading, and every cross-reference is a link to the clause it names.
- The wording text is otherwise unchanged. It is a conversion to clause source and does not amend any cover.
- Each of the 12 drafted endorsements now carries a platform trigger: the questions it reads, default rules and underwriter responses.
- The endorsement library lists the drafted endorsements. The reserved codes E11 and E14 to E20 are noted without titles.
