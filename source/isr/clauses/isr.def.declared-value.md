---
id: isr.def.declared-value
type: definition
heading: Declared Value
since: 1.1.0
status: draft
---

The value you declare, as shown in the schedule, for the Insured Property at each Situation by category of property, or for each item of [[ref:isr.section.business-interruption]]. Declared Values are used to calculate premium and to apply [[ref:isr.pay.co-insurance]] and [[ref:isr.pay.bi-loss]]. They are not limits.
