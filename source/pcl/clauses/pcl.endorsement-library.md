An endorsement applies only if its code is shown in the schedule. Each endorsement changes this policy only as it states, and is read together with the variables shown for it in the schedule. Where an endorsement and the rest of this policy conflict, the endorsement applies to the extent of the conflict. If a variable an endorsement needs is not shown in the schedule, the default stated in the endorsement applies; if it has no default, the endorsement does not apply until we show the variable in the schedule.

| Code | Endorsement | Effect |
|---|---|---|
| E01 | Worldwide Cover | Covers every category anywhere in the world |
| E02 | Vault Storage | Sets the cover for jewellery and watches kept in a vault |
| E03 | Jewellery Kept in a Safe | Requires valuable jewellery to be kept in a safe when not worn |
| E04 | Wine Temperature Failure | Covers wine spoiled by a failure of cellar temperature control |
| E05 | Professional Use of Instruments | Covers musical instruments used to earn an income |
| E06 | Exhibition and Loan | Covers items lent to a gallery, museum or exhibition |
| E07 | Unoccupied Premises | Continues theft cover while the premises are unoccupied |
| E08 | Self-Managed Superannuation Fund | Sets terms for a collection owned by a self-managed superannuation fund |
| E09 | Valuations to Follow | Limits cover for items whose valuations are still to be given to us |
| E10 | Interested Party | Notes a financier or other party's interest |
| E11 | Lloyd's Underwriters | Adds Lloyd's several liability, service of suit and complaints terms |
