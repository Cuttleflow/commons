An endorsement applies only if its code is shown in the schedule. Each endorsement changes this policy only as it states, and is read together with the variables shown for it in the schedule. Where an endorsement and the rest of this policy conflict, the endorsement applies to the extent of the conflict. If a variable an endorsement needs is not shown in the schedule, the default stated in the endorsement applies; if it has no default, the endorsement does not apply until we show the variable in the schedule.

| Code | Endorsement | Effect |
|---|---|---|
| E01 | Agreed Value Weekly Benefit | Removes the income test from the weekly benefit |
| E02 | Business Expenses | Reimburses fixed business expenses while you are disabled |
| E03 | Occupational Cover Only | Limits cover to while you are working |
| E04 | Non-Occupational Cover Only | Limits cover to outside work |
| E05 | Named Hazardous Pursuit | Writes back the hazardous pursuits named |
| E06 | Named Pursuit Exclusion | Excludes the pursuits named |
| E07 | Specific Condition Exclusion | Excludes a named medical condition |
| E08 | Accepted Pre-existing Condition | Accepts a named pre-existing condition |
| E09 | Weekly Benefits to Age 70 | Extends weekly benefits to age 70 |
| E10 | Extended Overseas Cover | Extends overseas cover beyond 90 days |
| E11 | Capital Benefits Only | Removes weekly benefits |
| E12 | Increased Additional Benefits | Increases the funeral and rehabilitation limits |
| E13 | Lloyd's Underwriters | Adds Lloyd's several liability, service of suit and complaints terms |
| E14 | Confirmation of Cover for a Principal | Confirms cover to a principal without giving it rights |
