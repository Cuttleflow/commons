An endorsement applies only if its code is shown in the schedule. Each endorsement changes this policy only as it states, and is read together with the variables shown for it in the schedule. Where an endorsement and the rest of this policy conflict, the endorsement applies to the extent of the conflict. If a variable an endorsement needs is not shown in the schedule, the default stated in the endorsement applies; if it has no default, the endorsement does not apply until we show the variable in the schedule.

| Code | Endorsement | Effect |
|---|---|---|
| E01 | Difference in Conditions | Covers the specified differences between the followed policy and other underlying insurance |
| E02 | Reinstatement of the Limit of Liability | Reinstates the limit of liability once, for an additional premium |
| E03 | Drop-down for Underlying Aggregate Exhaustion | Moves the attachment point down when an aggregate underlying limit is reduced by paid loss |
| E04 | Defence Costs in Addition to the Limit | Pays defence costs in addition to the limit of liability where the followed policy pays them within its limit |
| E05 | Self-insured Retention | Allows a self-insured retention in place of underlying insurance for a specified cover |
| E06 | Multi-year Underlying | Fixes the underlying insurance for a multi-year followed policy |
| E07 | USA and Canada | Covers claims brought in the USA and Canada where the followed policy covers them |
| E08 | Specified Exclusion Changes | Changes specified exclusions of the followed policy for this layer only |
| E09 | Drop-down for Underlying Insurer Insolvency | Moves the attachment point down to replace an insolvent underlying insurer, to a sub-limit |
