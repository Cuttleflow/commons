An endorsement applies only if its code is shown in the schedule. Each endorsement changes this policy only as it states, and is read together with the variables shown for it in the schedule. Where an endorsement and the rest of this policy conflict, the endorsement applies to the extent of the conflict. If a variable an endorsement needs is not shown in the schedule, the default stated in the endorsement applies; if it has no default, the endorsement does not apply until we show the variable in the schedule. These endorsements are for use with this wording at version 1.0.x.

| Code | Endorsement | Effect |
|---|---|---|
| E01 | Third-party Recall Costs | Covers your customers' recall costs that you are legally liable for, to a sub-limit |
| E02 | Product Extortion | Covers threats of malicious tampering and extortion demands, to a sub-limit |
| E03 | Adverse Publicity | Covers loss when publicity about contamination of similar products stops your sales |
| E04 | USA and Canada | Covers insured products sold in the USA and Canada, to a sub-limit |
| E05 | Allergen Retention | Applies a higher retention to insured events caused by an undeclared allergen |
| E06 | Untraceable Products | Limits recall and replacement costs where the insured products cannot be traced by batch |
