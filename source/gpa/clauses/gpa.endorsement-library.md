An endorsement applies only if its code is shown in the schedule. Each endorsement changes this policy only as it states, and is read together with the variables shown for it in the schedule. Where an endorsement and the rest of this policy conflict, the endorsement applies to the extent of the conflict. If a variable an endorsement needs is not shown in the schedule, the default stated in the endorsement applies; if it has no default, the endorsement does not apply until we show the variable in the schedule.

| Code | Endorsement | Effect |
|---|---|---|
| E01 | Voluntary Workers | Covers voluntary workers, per head, injury only |
| E02 | Journey Cover | Limits a category to journeys |
| E03 | Sports Teams | Covers registered players and officials, per head |
| E04 | Overseas Secondment | Covers secondment overseas, with evacuation |
| E05 | Named Hazardous Pursuit | Writes back the hazardous pursuits named |
| E06 | Fly-in Fly-out | Covers fly-in fly-out rosters and charter flights |
| E07 | Extended Benefit Period | Extends the benefit period to 260 weeks or age 65 |
| E08 | Corporate Travel Interface | Coordinates with a corporate travel policy |
| E09 | Weekly Benefits to Age 70 | Extends weekly benefits to age 70 |
| E10 | Passive War and Political Risk Zones | Covers passive war risk in named countries |
| E11 | Workers Compensation Top-Up | Makes weekly benefits top up workers compensation |
| E12 | Key Person Top-Up | Raises benefits for named key persons |
| E13 | Lloyd's Underwriters | Adds Lloyd's several liability, service of suit and complaints terms |
| E14 | Enterprise Agreement Terms | Applies enterprise agreement terms |
| E15 | Students | Covers enrolled students, per head |
| E16 | Specific Condition Exclusion | Excludes a named condition for a named covered person |
