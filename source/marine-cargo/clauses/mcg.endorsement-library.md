An endorsement applies only if its code is shown in the schedule. Each endorsement changes this policy only as it states, and is read together with the variables shown for it in the schedule. Where an endorsement and the rest of this policy conflict, the endorsement applies to the extent of the conflict. If a variable an endorsement needs is not shown in the schedule, the default stated in the endorsement applies; if it has no default, the endorsement does not apply until we show the variable in the schedule.

| Code | Endorsement | Effect |
|---|---|---|
| E01 | Temperature-Controlled Goods | Covers loss from failure of refrigeration on agreed terms |
| E02 | Used Goods | Limits cover for used goods to named risks |
| E03 | Own Vehicle Carriage | Sets conditions for goods carried in your own vehicles |
| E04 | Dangerous Goods | Records dangerous goods and the conditions for carrying them |
| E05 | Theft-Attractive Goods Excess | Applies a separate excess to theft of theft-attractive goods |
| E06 | Replacement Clause for Machinery | Applies the Institute Replacement Clause to machinery |
| E07 | Import Duty and Taxes | Adds import duty and taxes to the insured value |
| E08 | Seller's Contingent Interest | Covers your interest in goods sold on terms where the buyer insures |
| E09 | Storage in Transit | Extends cover to storage beyond 7 days in the course of an inland transit |
| E10 | High-Risk Areas | Records transits to or from high-risk or sanctioned areas and the terms that apply |
