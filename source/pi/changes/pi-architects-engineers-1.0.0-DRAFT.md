First release as an integrated profession wording. It replaces the endorsement MERIDIAN-PI-ARCH-v1.0.0 (June 2026), which was written against base PI v1.0.0. The same terms are also published as an endorsement to base PI v1.3.0-DRAFT; both are generated from one source.

- Professional services: scope carried over from the v1.0.0 endorsement. Added limb (m), so that a discipline not listed (for example geotechnical, hydraulic or fire engineering) is covered only when shown in the schedule.
- Registered Designs and Plagiarism extension: replaces the v1.0.0 "Modified Extension — Intellectual Property". The v1.0.0 clause deleted a base extension that no longer exists and, read literally, removed cover for moral rights and passing off. The base Claims Against You clause already covers copyright, trademark, moral rights, passing off and breach of confidence; this extension adds registered designs and plagiarism.
- Subcontractors: the v1.0.0 conditions (subcontractor insured, indemnity in the subcontract, fees declared) are not carried over. They would have narrowed the base Subcontractors and Outsourcers extension. Reinstating them is an open coverage question.
- Construction Work exclusion: the v1.0.0 text excluded "supervision" of construction, which removed cover for contract administration and site inspection. This version carves design, contract administration, site inspection, site observation and certification services back in.
- Patent Infringement, Project Management Activities, Warranties and Liquidated Damages, and Excluded Engineering Activities exclusions: carried over from v1.0.0 with drafting tidied. Two v1.0.0 exclusions are omitted because the base wording already contains them (Products; contractual liability beyond liability at law).
- Cross-references cite clause headings; there are no clause numbers.
