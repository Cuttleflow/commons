Remediation following the Claude pre-review of 2 November 2026. Built on base PI 1.5.0-DRAFT.

- Base changes flow through: Financial Services exclusion, Sanctions, Statutory Liability, Other Insurance, Cancellation, the Insurance Contracts Act 1984 (Cth) condition and the other changes listed for base PI 1.5.0-DRAFT.
- Professional services: the qualification test now applies to each discipline, instead of requiring a qualification in engineering, architecture, surveying or quantity surveying for every service. This lets town planning, landscape design, interior design, drafting and project management be covered as listed. Tax depreciation schedules are also subject to the Licences, Registrations and Accreditations condition. Flagged for review on the Tax Practitioners Board insurance requirement. Default set for underwriter confirmation.
- NSW Registered Practitioners extension: states that the date of first registration applies in place of the schedule date. Flagged for review on whether a prior-knowledge exclusion may apply.
- Liquidated Damages and Contractual Penalties exclusion: now has a carve-back for an amount you would have been liable for without the contract. Default set for underwriter confirmation.
- Excluded Engineering Activities exclusion: the dam height is now a schedule item, with 6 metres as the default. Default set for underwriter confirmation.
