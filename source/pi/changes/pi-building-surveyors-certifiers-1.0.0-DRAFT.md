First release as an integrated profession wording, built on base PI 1.4.0-DRAFT. For building surveyors and certifiers it replaces the endorsement MERIDIAN-PI-SURV-v1.0.0 (June 2026); land, cadastral and quantity surveyors move to the Architects and Engineers wording.

- Professional services: building surveying, assessment, approval, certification and inspection under state building law, and related compliance reports, provided by a person registered for that function and class of building.
- New extensions: Cover from First Registration (for laws, such as the NSW certifier insurance rules, that require cover for work since first registration) and Building Regulator Proceedings.
- Construction Work exclusion, with the inspection and certification carve-back, taken from the Architects and Engineers wording.
- Optional endorsements: External Cladding Exclusion (in each state's permitted form), Apartment Buildings Sub-limit, Retirement Run-off (adds cover), Pool Safety Inspections (adds cover) and Fire Performance Solutions Exclusion.
