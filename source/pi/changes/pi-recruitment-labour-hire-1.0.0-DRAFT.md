First release as an integrated profession wording, built on base PI 1.4.0-DRAFT. It replaces the endorsement MERIDIAN-PI-RECR-v1.0.0 (June 2026).

- Deleted: the obstetric services definition and exclusion, which did not belong in this wording, and the high-risk training exclusion; the base Bodily Injury and Property Damage exclusion applies.
- Professional services cover recruitment, executive search, labour hire selection and placement, testing, outplacement and HR consulting. Work performed by on-hired workers for a host is excluded unless the On-hired Workers endorsement applies.
- New extension: Wrongful Placement. New exclusions: Wages, Superannuation and Employer Payments; Work Performed by On-hired Workers; Migration Advice.
- Optional endorsements: On-hired Workers (adds cover, rebuilt from the June optional extension), Payroll Administration (adds cover), High-Risk Placements Exclusion, Labour Hire Licence Condition, Migration Advice (adds cover) and Automated Screening Exclusion.
