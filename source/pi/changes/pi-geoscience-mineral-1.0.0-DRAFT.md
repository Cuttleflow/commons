First release as an integrated profession wording, built on base PI 1.4.0-DRAFT. It replaces the endorsement MERIDIAN-PI-GEOL-v1.0.0 (June 2026).

- Public reports are covered when each competent person holds the membership that the applicable reporting code requires. The condition names the JORC Code, the VALMIN Code or an equivalent CRIRSCO code, so it continues to work under the JORC Code 2026.
- The public report deductible is corrected. The June text ("the lesser of 0.25% or $10,000, maximum $250,000") could never exceed $10,000. The Public Report Excess endorsement now defaults to the greater of $10,000 and 0.25%, capped at $250,000.
- Mineral extraction and geological estimates for disclosure documents are no longer excluded.
- New extensions: Contributing Competent Persons and Securities Exchange Queries. New exclusions: Guarantees of Grade, Tonnage or Price, and Excluded Geoscience Activities.
- Optional endorsements: Public Report Excess, Petroleum Reserves Estimation (adds cover), North American Reporting Exclusion, Tailings and Mine Closure Exclusion and Mineral Asset Valuation Sub-limit.
