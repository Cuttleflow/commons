The following services provided to a third party for a fee:

(a) geological, mineral and exploration consulting;

(b) the estimation of mineral resources and ore reserves;

(c) the technical assessment and valuation of mineral assets;

(d) geophysics, geochemistry and hydrogeology;

(e) public reports, which means a report prepared for release to a securities exchange, for a disclosure document, or for any other public document about a mineral asset, and any contribution to such a report; and

(f) any other service shown in the schedule as a professional service.

A public report is a professional service only if each competent person or specialist who signs it on your behalf holds the professional membership that the reporting code applying to the report requires. A competent person or specialist who does not sign the report on your behalf, including one whose work you rely on, does not affect this condition.

In this definition, a competent person is a person named in a public report as responsible for the estimate of mineral resources or ore reserves, or the exploration results, that it reports, and a specialist is a person named in a public report as responsible for a technical or valuation opinion that it reports, in each case as the reporting code applying to the report uses those terms. A reporting code is the JORC Code, the VALMIN Code or an equivalent code recognised by the Committee for Mineral Reserves International Reporting Standards (CRIRSCO).

[[ref:pi.excl.financial-services]] does not apply to a public report that is a professional service, unless the work involves financial product advice, dealing in a financial product or a credit activity.
