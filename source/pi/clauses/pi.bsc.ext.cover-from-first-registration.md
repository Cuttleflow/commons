type: extension
heading: Cover from First Registration
profession: building-surveyors-certifiers
since: 1.0.0
status: draft
note: For Part 3 of the Building and Development Certifiers Regulation 2020 (NSW), which requires cover for liability since first registration. Written generally so that it also applies if another state
  adopts the same rule. Counsel to confirm.
---

Where a law under which you are registered as a building surveyor or certifier requires your insurance to cover liability for work carried out since you were first registered, the retroactive date, for a claim arising from that work, is the date you were first registered under that law, if that date is earlier than the retroactive date shown in the schedule.

This extension does not affect [[ref:pi.excl.prior-known-circumstances]].
