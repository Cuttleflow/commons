The table shows which exclusions apply in full to each cover and which contain a carve-back. "Applies" means the exclusion applies in full. "Carve-back" means the exclusion applies except to the extent its own text preserves cover. Read the exclusion itself for the precise limit of any carve-back. The table is a guide only; the exclusions govern.
