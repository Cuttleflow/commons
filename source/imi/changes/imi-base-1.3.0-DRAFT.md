This is the first release of the Meridian Investment Managers Indemnity Insurance wording built from clause source in the Commons. It replaces version 1.2.0 (July 2026). Changes from version 1.2.0:

- Clause numbers are removed. Each clause is identified by its heading, and every cross-reference is a link to the clause it names. The cover, exclusions, limits and conditions of version 1.2.0 are unchanged.
- Four clauses with headings that named a section now say so in the heading: Dishonesty and Fraud, Notify Claims, Notify Circumstances and Trading Losses each name the sections to which they apply.
- The endorsement library has 14 endorsements, each with operative text, schedule variables and a platform trigger. Version 1.2.0 listed titles only, and several titles described endorsements as not yet available.
- The guide in Appendix A is unchanged. It is not part of the contract.
- Six points are marked [WP REVIEW] for the Wording Partner. They are all in the new endorsement text.
